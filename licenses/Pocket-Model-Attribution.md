Out Loud downloads the supported native `.safetensors` model files through
Settings. The exact repository paths, immutable revisions, sizes and content
hashes are recorded in the installed model inventory. The installer contains
no model weights.

Downloaded weight files retain their original bytes; Out Loud does not retrain,
quantize or convert them to another model format. Local runtime configuration
and application inventory are separate from the model files.
