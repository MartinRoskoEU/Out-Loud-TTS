# Out Loud 0.4.4

- Import multiple voices with one confirmation, filename-based names, existing
  conflict handling and a result report in the notification panel.
- Keep uninstall progress responsive, including final cleanup verification;
  removal has no Cancel action.
- Check for new Out Loud versions at startup and in Settings. Available updates
  link to the published GitHub release for manual installation.
- Match the Out Loud update card to the runtime card and reduce repeated work
  during completed maintenance archive verification.
- Reuse locked original-file verification and verified copy results; register
  each exact file path only once per Windows in-use check.
- Keep the installation window responsive and support safe cancellation during
  preparation; signing, publication and completion must finish uninterrupted.
- Restore a missing Pocket TTS executable with **Repair runtime** in Settings,
  without reinstalling Out Loud. Repair downloads the selected version from
  Kyutai and verifies its original content identity.
- Keep the saved model selection while the runtime is unavailable. Models,
  voices and Settings are preserved; antivirus settings are not changed.
- Accept identical restored files throughout the protected installation
  inventory. Verify their original content and hold read leases during staging;
  retain strict current identity checks during publication and recovery.
