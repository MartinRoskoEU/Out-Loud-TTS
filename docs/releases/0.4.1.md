# Out Loud 0.4.1

Out Loud 0.4.1 adds confirmed model updates and combines runtime and model
update checks into a single Settings action.

## What's new

- **One Check for updates button:** check the Pocket TTS runtime and installed
  models from the top of Settings. Results remain beside the relevant items.
- **Confirmed model updates:** when an update is available, **Update** appears
  before **Remove** on the model row. Downloads use the official public repository
  and an exact revision, with file integrity and tensor-layout verification before
  activation. Each model/runtime update still requires separate confirmation.
- **Preserved model selection:** updating a selected model keeps it selected.
  Updating another model does not select it. Failure or cancellation before
  activation preserves the previous installation and selection.
- **Verified cleanup:** superseded model files are removed when no installed model
  references them. Shared and busy files remain protected, and pending cleanup is
  retried at startup. Previous versions are not retained for rollback.
- **Corrected runtime message:** the confirmation dialog now explains removal of
  verified inactive downloaded runtime versions after successful activation.

Model updates retain the application's trusted configuration and asset paths.
Updates requiring changed tensor names, shapes or dtypes need a compatible Out Loud
release. Existing native `.safetensors` voice profiles and SAPI registrations are
not rewritten by model updates.

## Installation and upgrades

Download `OutLoud-Setup.exe` and `OutLoud-Setup.exe.sha256`. Run the installer to
upgrade an existing installation. Managed voices, models, runtime updates and
Settings are preserved by application upgrades.

Requirements remain Windows 11 native x64, build 22000 or later, a compatible
AVX2/FMA-capable processor, and administrator approval for installation and startup.
Models and voice profiles are not bundled. Installed synthesis works offline.
