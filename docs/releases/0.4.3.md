# Out Loud 0.4.3

- Import now distinguishes identical voice profiles from existing voice names.
  Identical profiles are rejected even when a different name is entered.
- Voice names are unique, ignoring case and surrounding whitespace. A different
  profile with an existing name offers Replace voice, Change name or Cancel.
- Confirmed replacement keeps the existing name, library ID and Windows speech
  identity, with protection for voices currently in use and recovery after an
  interrupted replacement.
- Fixed replacement backup cleanup permissions and clarified recovery errors.

Download `OutLoud-Setup.exe` and `OutLoud-Setup.exe.sha256`. Application upgrades
preserve managed voices, models, runtime updates and Settings.
