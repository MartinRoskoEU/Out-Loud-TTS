# Out Loud 0.4.2

Out Loud 0.4.2 is a bugfix release for window minimization and Voice Library
error handling.

## Fixes

- Fixed the application closing unexpectedly when minimized. WinUI can report
  a negative caption-button inset during minimization and restoration; Out Loud
  now retains the last valid title-bar width until valid geometry is available.
- Unexpected Voice Library workflow and detail-dialog errors are reported in
  the application instead of escaping through button event handlers.
- If a pending Voice Library task fails while closing, the window stays open
  and displays an error so the user can review it and retry closing.

## Installation and upgrades

Download `OutLoud-Setup.exe` and `OutLoud-Setup.exe.sha256`. Run the installer to
upgrade an existing installation. Application upgrades preserve managed voices,
models, runtime updates and Settings.

Requirements remain Windows 11 native x64, build 22000 or later, an
AVX2/FMA-capable processor, and administrator approval for installation and startup.
Models and voice profiles are not bundled.

## Validation recorded for this release

- 24 isolated UI regression checks passed using the updated production method
  bodies. They exercised three minimize/restore cycles, maximize/restore, actual
  negative WinUI insets, synchronous and asynchronous workflow errors,
  duplicate-operation blocking, and a failed pending task during window closing.
- The isolated harness used a temporary WinUI window and simulated workflow
  failures. It did not initialize the installed application, models or SAPI.
- Release x64 native components and self-contained WinUI installer packaging
  completed. All 592 packaged file hashes and the versions of eight project
  components were verified; the installer checksum matches its SHA-256 file.
- Live installation, upgrade, playback and Windows Sandbox acceptance testing
  were not performed.
