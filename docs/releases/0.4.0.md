# Out Loud 0.4.0

Out Loud 0.4.0 introduces a WinUI 3 desktop interface and uses the official
Pocket TTS Rust runtime as its only synthesis backend.

## What's new

- **Voice Library:** import, export, inspect and remove native `.safetensors`
  voice profiles, with machine-wide Windows SAPI registration.
- **Voice Tester:** test registered voices, edit test text, control playback
  and export speech to WAV.
- **Model management:** download, verify, select and remove supported
  synthesis-only models, and check for model updates.
- **Runtime updates:** check for and install verified updates from the official
  Pocket TTS releases.
- **Shared configuration:** models, voices and Settings are available to all
  Windows accounts.
- **Updated interface:** refined layouts, semantic status colors and clearer
  messages for common errors.
- **Installer and uninstaller:** offline prerequisites, visible progress,
  improved diagnostics and automatic cleanup of completed maintenance files.
- Updated documentation and third-party license notices.

The legacy C++ inference backend and OLV/OLP workflows have been removed.
Native voice profiles retain their original bytes and remain independent of
model versions. Speech uses the model explicitly selected in Settings.
Model update checks do not automatically replace installed weights; runtime
updates require explicit confirmation.

## Requirements

- Windows 11 native x64, build 22000 or later.
- AVX2/FMA-capable processor.
- Administrator approval for installation and application startup.

## Getting started

1. Download and run `OutLoud-Setup.exe` from the
   [0.4.0 release](https://github.com/MartinRoskoEU/Out-Loud-TTS/releases/tag/v0.4.0).
2. Install a model in Settings and select it.
3. Import a native `.safetensors` voice profile in Voice Library.
4. Test it in Voice Tester or use it through a compatible Windows SAPI application.

Models and voice profiles are not bundled. Once installed, speech synthesis
works offline. External SAPI applications do not require elevation.

Downloads include `OutLoud-Setup.exe` and its SHA-256 checksum file.
Upgrades preserve managed data. Confirmed uninstall removes verified Out Loud-owned
resources while preserving unknown user files and shared Microsoft runtimes.
