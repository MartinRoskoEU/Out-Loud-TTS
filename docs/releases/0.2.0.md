# Out Loud 0.2.0

Out Loud 0.2.0 updates the official Kyutai Pocket TTS English model and simplifies
voice management while preserving the OLV v1 format and existing voice library.
The installer is prepared locally for approval; no public upload or 0.2.0 tag has
been created by this preparation workflow.

## Changes

- Updated official stable English model weights, matching `english_2026-09_2`,
  with the same six-layer English architecture and tokenizer.
- Automatic developer-side discovery of official model updates, verified source
  downloads, existing BF16-to-OLP conversion, validation and model history.
- Engine version advances automatically when verified model weights change.
  Integrity pins, transactional publication and rollback protect model updates.
- Voice Manager has no per-voice model classifications or Legacy/Unknown warnings.
  Voice selection depends on supported structure, integrity and normal health/
  SAPI registration checks. OLV identifiers remain unchanged serialized data.
- Existing `.olv` and supported prepared six-layer English `.safetensors` profiles
  remain importable and playable. Format, bounds, dimensions, dtype, finite-value,
  integrity, safe-path and memory-safety validation remain mandatory.
- Explicit version-aware development upgrades preserve signing/registration
  ownership and journal installed version metadata together with the full payload.
- Longer default Voice Tester passage for manual listening comparisons.

## Voice quality and upgrading

Existing profiles remain importable and playable when structurally supported.
Profiles prepared with older model weights may sound different or exhibit
artifacts with this update. Structural support does not guarantee acoustic
quality, speaker similarity, prosody or end-of-speech behavior for every profile.
For best quality, users may need to prepare new profiles with the updated model
and their original reference audio. Out Loud does not automatically convert or
regenerate existing voices and cannot recover original reference audio from a
prepared voice cache.

Close World of Warcraft, Voice Manager and other SAPI clients before setup. The
existing in-place maintenance path preserves the installation location, managed
voice files/metadata/names/IDs, user configuration, COM/SAPI identity and
installation-owned certificate/key. Changed or locked files cause checked refusal
or recovery; applications are not forcibly terminated. Export voice backups
outside the managed library before intentional complete uninstall: **complete
uninstall permanently deletes managed voices and owned application data**.

## Package and requirements

Use `OutLoud-Setup-0.2.0.exe` with `OutLoud-Setup-0.2.0.exe.sha256`. Requires Windows
11 native x64 and administrator approval. Setup offers missing system Microsoft
VC++ v14 x64 and .NET 10 Desktop x64 runtimes with consent. The model/tokenizer,
Voice Manager, native engine/bridge/import helper, management utilities, resources
and required notices are included; **voices, recordings and the WoW addon are not**.

The installer remains publisher-unsigned under the established policy. Local
installation-owned engine signing is separate; upgrades reuse the existing
certificate and trust. This preparation does not execute setup, alter the working
installation, push Git changes, create a 0.2.0 tag or publish a GitHub release.
