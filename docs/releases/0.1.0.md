# Out Loud 0.1.0

The first public release of Out Loud brings offline English narration to the
Out Loud World of Warcraft addon through Pocket TTS and Windows SAPI5.

- Import, test, replace, remove and export compatible voices in Voice Manager.
- Export synthesized speech to WAV.
- Adjust SAPI speech speed from -10 to +10 with pitch-preserving Sonic processing.
  The normal rate retains the original audio samples and streaming behavior.
- Install through the Windows setup wizard with checked prerequisites, explicit
  license/use-policy acceptance and installation-owned SAPI registration/signing.

## Download and install

Download **OutLoud-Setup-0.1.0.exe** and its **OutLoud-Setup-0.1.0.exe.sha256**
checksum. Requires **Windows 11 native x64** and administrator approval.
Setup offers missing Microsoft VC++ v14 x64 and .NET 10 Desktop x64 prerequisites.
The English model and tokenizer are bundled; **voices and the WoW addon are not**.
Import your own compatible `.olv` or prepared Pocket `.safetensors` voice.

Close WoW and other SAPI clients before running setup. The installer is
publisher-unsigned; installation-specific local engine signing is separate.
See the [README](https://github.com/MartinRoskoEU/Out-Loud-TTS#readme) for setup
and usage instructions.

## Before uninstalling

**Uninstall permanently deletes all managed voices and owned application data.**
Export voices you want to keep outside the managed library first. External
backups and shared Microsoft runtimes remain installed.
