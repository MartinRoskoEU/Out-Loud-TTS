# Out Loud 0.1.0

The first public release of Out Loud brings offline English narration to the
Out Loud World of Warcraft addon through Pocket TTS and Windows SAPI5.

- Import, test, replace, remove and export compatible voices in Voice Manager.
- Import supported legacy Pocket TTS 6L voice states with automatic normalization
  into `.olv`, preserving the original `.safetensors` file.
- Identify known incompatible Kyutai TTS 1.6B / DSM profiles and explain the
  supported Pocket TTS 6L format in an **Incompatible Voice Profile** notice.
- Export synthesized speech to WAV.
- Adjust SAPI speech speed from -10 to +10 with pitch-preserving Sonic processing.
  The normal rate retains the original audio samples and streaming behavior.
- Install through the Windows setup wizard with checked prerequisites, explicit
  license/use-policy acceptance and installation-owned SAPI registration/signing.

## Download and install

Download **OutLoud-Setup-0.1.0.exe** and its **OutLoud-Setup-0.1.0.exe.sha256**
checksum. Requires **Windows 11 native x64** and administrator approval.
Setup offers missing Microsoft VC++ v14 x64 and .NET 10 Desktop x64 prerequisites.
The English model and tokenizer are bundled; **voices and the WoW addon are not**.
Import your own compatible `.olv` or prepared six-layer English Pocket TTS
`.safetensors` voice. Older `current_end` states and states without an explicit
zero-padding tensor are supported when they pass the existing strict validation.
The importer checks the complete tensor structure; matching shapes do not prove
model provenance. DSM `speaker_wavs` profiles, other architectures and raw audio
are incompatible with this import path.

Close WoW and other SAPI clients before running setup. The installer is
publisher-unsigned; installation-specific local engine signing is separate.
See the [README](https://github.com/MartinRoskoEU/Out-Loud-TTS#readme) for setup
and usage instructions.

## Before uninstalling

**Uninstall permanently deletes all managed voices and owned application data.**
Export voices you want to keep outside the managed library first. External
backups and shared Microsoft runtimes remain installed.

CC BY 4.0 with attribution and a separately presented prohibited-use policy.
Sonic: Apache 2.0. Complete licenses and notices are included.

English only. Windows 10, ARM64, 32-bit Windows and Windows Server are unsupported.
Raw-audio voice creation and XML fragment-specific rate adjustments are not included.

Updates support additions and removals in the managed file list, including the
earlier 23-file development inventory. Managed voices, settings, SAPI registration,
installation identity, local signing certificate and custom installation directory
are preserved. Failed native publication restores the previous files and inventory;
unknown or modified files cause a safe refusal.

The production build automatically cleans verified intermediate artifacts while
retaining required release stages, publication records, the current and previous
successful publication pairs, and externally referenced diagnostic evidence.
